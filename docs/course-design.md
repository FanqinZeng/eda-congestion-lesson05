# 概率需求：两条可能的路，一张可验证的图

本课按用户授权自主完成并发布。消费 skill 1.0.0；初始快照保存在 docs/skill-history/v1。采用既有静态网页与真实双语动画流水线，不额外扩张为完整拥塞课程。

## 口径裁决

上游讲稿要求两条L各半概率且转角不重复，helper却按四条leg各归一化，单位与RUDY不一致。本课默认采用“路径占用概率”：每条L先把完整路径的GCell去重，再每格加0.5；两种候选路线共享的端点合计1。它是含端点的toy占用模型，同一格内的两个pin占用该格1单位，不等同于物理导线长度。多pin保留bbox中心星形近似，每spoke权重1/p。

另提供明确标记的“上游helper兼容”模式，逐leg均摊0.5，允许与固定上游实现交叉对照；不将它称为每格通过概率。RUDY原始模式将HPWL均摊到bbox。默认对比将每个net的RUDY总质量匹配该net的L需求总质量，比较空间分布；原始RUDY保留用于观察单位差异。模式、总量和容量单位始终显示，不隐瞒修正。

主例为4×4 GCell上的对角两pin：端点(1,1)/(10,10)，chip12×12、cell3×3。两条L各7格，需求总和7，端点1、其他边界0.5、内部0；等总量RUDY每格7/16。容量0.6时L有2个热点，总overflow0.8；等总量RUDY没有热点。这说明更均匀的估计不等于更真实。附教师4×2/six-net例、直线、同格、多pin近似。

## 学习路径与产物

双语主页从真实问题、影片、单net逐路分配、双热图实验、反例和六题解析进入在线讲义及可编辑运行的Python。输入表、键盘和选择预设与图形等价；按需加载本地Pyodide Worker。双语播放器沿用已修复的界面联动机制，全部资料直接在线读。

中文和英文分别制作完整旁白动画，统一语义scene id与字幕对齐。场景展示两条路径展开、去重转角、概率累加、热图、容量阈值、RUDY空间差异、同格与星形近似、真实实验回扣。深蓝绿底、青绿暖金、象牙文字，1080p/30fps；不重复平移同一图凑时长。
